## Margins — Book Tracking App

A warm, paper-feel reading tracker with shelves, a kanban board, and rich book detail pages. Built on TanStack Start + Lovable Cloud (Supabase).

### Design system

Add tokens to `src/styles.css`:
- Colors (oklch equivalents of the hex palette): `--cream`, `--paper`, `--sage`, `--forest`, `--terra`, `--honey`, `--dust`, `--ink`, `--mist`, mapped to semantic tokens (`--background: var(--cream)`, `--card: var(--paper)`, `--primary: var(--forest)`, `--accent: var(--terra)`, `--border: var(--mist)`, `--foreground: var(--ink)`, etc.).
- Fonts via Google Fonts `<link>` in `__root.tsx`: Newsreader (display/headings), Manrope (UI/body), JetBrains Mono (numbers/metadata). Register `--font-serif`, `--font-sans`, `--font-mono`.
- Radii: card 24px, pill nav fully rounded.
- Shadow tokens: `--shadow-paper` (soft layered), `--shadow-lift` (hover).

### Backend (Lovable Cloud)

Enable Cloud, then create schema + RLS:

**Tables**
- `profiles` — id (uuid, FK auth.users), display_name, avatar_url, yearly_goal (int default 12), created_at. Auto-created via trigger on `auth.users` insert.
- `books` — id, user_id, title, author, format ('print'|'ebook'|'audiobook'), cover_color, cover_text_color, cover_generic bool, bookmark_color, created_at.
- `user_books` — id, user_id, book_id (FK), status enum ('want','reading','later','dnf','loved','liked','meh'), current_page, total_pages, current_time, total_time, progress_pct, started_at, finished_at, rating (1-5), note, board_position int (for kanban order).
- `reading_sessions` — id, user_id, book_id, pages_read, minutes, started_at, ended_at.
- `highlights` — id, user_id, book_id, quote_text, page_number, created_at.
- `notes` — id, user_id, book_id, content, created_at.

**Security**
- RLS on every table: `user_id = auth.uid()` for select/insert/update/delete.
- Status as Postgres enum `book_status`.
- Trigger `handle_new_user()` (security definer) creates a profile row + seeds 6–8 sample books across shelves on signup.

**Auth**
- Email/password + Google OAuth (managed by Cloud).
- Routes: `/login`, `/signup`. Protected subtree under `_authenticated/`.

### Routes

- `src/routes/__root.tsx` — global head (fonts, meta), QueryClientProvider, Toaster.
- `src/routes/login.tsx`, `src/routes/signup.tsx` — auth forms with Google button.
- `src/routes/_authenticated.tsx` — `beforeLoad` redirects to `/login` if no session; renders pill nav + `<Outlet/>`.
- `src/routes/_authenticated/index.tsx` — **Homepage**: hero greeting (uses display_name + yearly goal progress: books finished this year / goal, current streak, pages this week), Currently Reading card grid, Up Next book-spine shelf (hover-lift), Recently Finished list with star ratings, Quote of the Day block (random highlight).
- `src/routes/_authenticated/board.tsx` — **Kanban**: 7 columns (Want / Reading / Later / DNF / Loved / Liked / Meh). Drag-and-drop using `@dnd-kit/core` + `@dnd-kit/sortable`. Drop updates `user_books.status` and `board_position`.
- `src/routes/_authenticated/books.$bookId.tsx` — **Book detail**: cover hero, progress bar, tabs (Overview / Notes / Quotes / Sessions). Add session, add note, add highlight. Edit/delete book.

### Components

- `components/PillNav.tsx` — sticky top, backdrop-blur, rounded-full, links: Home / Board / Add Book + avatar menu (logout).
- `components/BookCard.tsx` — three format variants:
  - **Print**: bookmark ribbon w/ notch (uses `bookmark_color`), solid page progress bar.
  - **Ebook**: scroll indicator dot, dashed progress bar, location/% label.
  - **Audiobook**: waveform spool badge (SVG bars), time progress (mm:ss / total).
  - States: paused (striped barber-pole progress), finished (gradient bg + "FINISHED" stamp overlay rotated -8°).
- `components/BookSpine.tsx` — vertical spine for Up Next shelf, hover translate-y.
- `components/GeneratedCover.tsx` — typographic cover (title + author) using `cover_color` bg + `cover_text_color`, Newsreader font.
- `components/StarRating.tsx` — 1–5 stars (terra fill).
- `components/AddBookModal.tsx` — shadcn Dialog: title, author, format radio, cover color picker (palette swatches from design tokens + custom), text color toggle (ink/paper), shelf select. Used for both add and edit.
- `components/ProgressBar.tsx` — variants: solid / dashed / striped / time.
- `components/SessionLog.tsx`, `components/NotesTab.tsx`, `components/QuotesTab.tsx`.

### Data layer

- `src/integrations/supabase/client.ts` (auto-generated by Cloud).
- `src/lib/queries.ts` — TanStack Query hooks: `useBooks`, `useUserBook`, `useUpdateStatus`, `useAddSession`, `useAddNote`, `useAddHighlight`, `useUpdateProgress`. All read/write through the browser Supabase client (RLS enforces ownership — no server functions needed).
- Realtime not required for v1; use query invalidation after mutations.

### Dependencies to add

`@dnd-kit/core`, `@dnd-kit/sortable`, `@dnd-kit/utilities`, `date-fns`. (shadcn, lucide, sonner, tanstack query already present.)

### Out of scope (v1)

- Cover image uploads (generated covers only).
- Social/sharing/friends.
- Import from Goodreads/CSV.
- Mobile app shell — responsive web only.

### Build order

1. Enable Lovable Cloud + schema migration + signup trigger w/ seed data.
2. Design tokens + fonts in `styles.css` and `__root.tsx`.
3. Auth pages + `_authenticated` guard + PillNav.
4. Shared components: GeneratedCover, BookCard variants, ProgressBar, StarRating.
5. Homepage with all sections.
6. Add/Edit Book modal.
7. Board view with drag-and-drop.
8. Book detail page with tabs (notes, quotes, sessions).
